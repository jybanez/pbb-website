Deployment options

Different communities can deploy PBB differently

Software-only deployment

PBB provides the software, configuration guidance, and managed software support. The organization provides or manages the local hardware and network environment.

Partner-funded node deployment

PBB software is installed on a locally provided or partner-funded node kit. Hardware may be purchased, donated, sponsored, or assembled through an approved deployment plan.

Bundled node deployment

A bundled node deployment may include hardware, setup, and support in one package. This requires a separate quotation because hardware, power, networking, travel, and training needs vary by site.

FAQ

Common deployment questions

Does the PHP 5,000/month fee include hardware?

No. The monthly fee is for managed support of the PBB software node. Hardware such as the mini PC/server, router, Wi-Fi access points, power backup, radios, storage, enclosure, and other field equipment is separate unless explicitly included in a deployment package or sponsored node kit.

Who provides the hardware?

Hardware may be provided by the LGU, donor, sponsor, NGO, school, business, or partner organization. In some deployments, hardware may be bundled separately through an approved node package.

What does PBB provide?

PBB provides the software ecosystem and managed support layer: local applications, emergency workflows, communication tools, maps, identity, synchronization, monitoring, configuration assistance, updates, documentation, and technical support.
